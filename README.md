# Customer Churn ML Platform

A small customer churn classifier built with pandas, scikit-learn and FastAPI. It includes data checks, model training, evaluation and a prediction endpoint.

## Overview

This project connects data preparation, model training and prediction in one small application. The sample data is synthetic.

## Quick start

Python 3.11+ is required.

Run from the repository root in PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:PYTHONPATH = "src"
.\.venv\Scripts\python.exe -m churn_ml.train --data data/customers.csv --model artifacts/churn.joblib
.\.venv\Scripts\python.exe -m uvicorn churn_ml.api:app --app-dir src --reload
```

On Linux/macOS, use `.venv/bin/python` and `export PYTHONPATH=src`.

If you need a fresh deterministic sample dataset, run `python scripts/make_dataset.py --out data/customers.csv`.

The API exposes `GET /health` and `POST /predict`. Example payload:

```json
{"tenure_months": 4, "monthly_charges": 72.5, "support_tickets_90d": 3, "contract": "month_to_month", "payment_method": "electronic"}
```

Training prints ROC-AUC, precision, recall and a confusion matrix for the held-out rows. The scores describe this generated dataset.

## How it works

- Schema checks reject missing columns, invalid categories, and non-finite numeric values.
- A scikit-learn `Pipeline` applies the same scaling and encoding during training and prediction, followed by logistic regression.
- A seeded stratified split makes experiments reproducible.
- The API returns a churn probability and applies a configurable default threshold of `0.5`.
- Model files are created locally and excluded from Git.

## Tests

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## Limitations

The data is small and generated by a script. It is useful for practising the workflow, but the scores do not show how the model would perform on real customers. Real use would need a suitable dataset, further validation and monitoring.
